                                 GESTOR DE GASTOS


Planteamiento del problema con fuentes técnicas

En la actualidad, la gestión eficiente de los gastos constituye un elemento fundamental para la sostenibilidad financiera y el logro de los objetivos organizacionales. Sin embargo, muchas empresas e instituciones enfrentan dificultades relacionadas con el control, registro y seguimiento de los gastos operativos, lo que genera inconsistencias en la información financiera, sobrecostos y una inadecuada toma de decisiones. La ausencia de herramientas y procedimientos adecuados para administrar los gastos limita la capacidad de las organizaciones para optimizar sus recursos y mantener un control efectivo de sus presupuestos. De acuerdo con el Project Management Institute (PMI), la gestión de costos es una de las funciones esenciales para garantizar el éxito de los proyectos y la eficiencia en el uso de los recursos disponibles.
Asimismo, la falta de mecanismo automatizados para el control de gastos puede ocasionar errores humanos, perdidas de información y dificultades para generar reportes financieros oportunos. Estas situaciones afectan directamente la planificación financiera y la capacidad de identificar áreas donde es posible reducir costos o mejorar la asignación de recursos. La norma ISO 21502:2020 destaca la importancia de establecer practicas adecuadas de gestión y control de costos para favorecer el cumplimiento de los objetivos organizacionales y el uso eficiente de los recursos.
Por otra parte, la contabilidad de costos y la gestión administrativa moderna señalan que el monitoreo continuo de los gastos permite mejorar la rentabilidad, fortalecer el control interno y facilitar la toma de decisiones estratégicas. Los enfoques de gestión de costos desarrollados por CIMA promueven el uso de herramientas de presupuestario, análisis de costos y control financiero para incrementar la eficiencia empresarial.
Como se ha investigado existen muchas técnicas de gestión de gastos y nos han mostrado la facilidad para poder ser utilizadas en diferentes asignaciones presupuestarias y sus análisis financieros como herramientas para facilitar la mayor producción y eficacia para la gestión de gastos todo esto incluye procesos de planificación.
Ante esta problemática, surgen la necesidad implementar un sistema de gestión de gasto que permita registrar, controlar y analizar de manera eficiente los gastos realizados por una organización. Dicho sistema contribuirá a mejorar la transparencia financiera, optimizar el uso de los recursos económicos y proporcionar información confiable para la toma de decisiones, favoreciendo así una administración más eficiente y sostenible.
Si ya bien se investigó que existen varias técnicas de gestión de gastos y se ha logrado visualizar que en base a la realidad que se vive en el mercado viendo la necesidad de cada empresa o institución se toma en cuenta lo necesario y buenas prácticas para solucionar problemas y dar propuestas y buena toma de decisiones eso nos ayudara a resolver la problemática que se nos pueda mostrar en el camino y nos ayudara a ver nuestros errores.

¿Cómo influye la implementación de un sistema de gestión de gastos en el control, seguimiento y optimización de los recursos financieros de una organización?
¿Cuáles son los principales problemas que presentan las organizaciones en el registro y control de sus gastos?
¿Qué técnicas de gestión de gastos permiten mejorar el control financiero y la toma de decisiones?
¿Cómo contribuye la presupuestacion al control eficiente de los gastos organizacionales?
¿de qué manera el análisis de variaciones ayuda a identificar desviaciones entre los gastos planificados y los gastos reales?
¿Qué indicadores financieros pueden utilizarse para medir la eficiencia en la gestión de gastos?




Delimitación


Teórica
Se estudiará la ingeniería de software aplicada a sistemas de gestión de gastos, con énfasis en calidad del software, eficiencia de desempeño, usabilidad y pruebas funcionales. Se tomará como referencia el modelo de calidad ISO/IEC 25010.

Temporal
El estudio se desarrollará durante el ciclo académico correspondiente a las cuatro entregas de Investigación Formativa, desde la definición del tema hasta la presentación de resultados y conclusiones.

Espacial o de contexto
Se estudiará un prototipo de gestor de gastos personales web desarrollado por el equipo de investigación. Las pruebas de uso se realizarán con participantes disponibles para el proyecto, según la planificación y los recursos del grupo.

Tecnológica
Se propone utilizar HTML5, CSS3 y JavaScript para la interfaz, PHP 8.2 para la lógica del servidor y MySQL 8.0 para la base de datos. El prototipo se ejecutará en un entorno local con XAMPP y Visual Studio Code. Estas versiones son propuestas iniciales y deberán confirmarse al configurar el entorno.


OBJETIVOS

Objetivo general
Comparar el rendimiento de Firebase,  y SQLite en operaciones de consulta e inserción utilizando diferentes volúmenes de datos bajo condiciones controladas.

Objetivos específicos
1.	Diseñar una base de datos experimental común para los tres gestores seleccionados.
2.	Implementar un banco de pruebas automatizado para ejecutar operaciones de consulta e inserción sobre diferentes volúmenes de datos.
3.	Medir el tiempo de respuesta de las operaciones evaluadas mediante múltiples ejecuciones para cada escenario experimental.
4.	Analizar las diferencias de rendimiento obtenidas entre Firebase y SQLite.
5.	Proponer recomendaciones para la selección de un gestor de bases de datos según las condiciones evaluadas y los resultados obtenidos.


Justificación
Técnica
Se examinará la implementación de una aplicación móvil nativa para Android desarrollada en Java, utilizando SQLite como gestor de base de datos embebido para la persistencia local, garantizando el almacenamiento seguro de transacciones financieras, el control presupuestario y la generación de indicadores de desempeño en tiempo real. Esta solución tecnológica se respaldará bajo los criterios de calidad del modelo ISO/IEC 25010 en cuanto a rendimiento, consumo eficiente de recursos en el dispositivo y usabilidad móvil. 
Académica
El desarrollo de la investigación permitirá consolidar los conocimientos teóricos y prácticos de la asignatura Programación III, aplicando los fundamentos del lenguaje Java en entornos móviles, la interacción con bases de datos relacionales y la ejecución de pruebas de desempeño bajo condiciones controladas. Asimismo, vinculará la teoría orientada a objetos con la resolución de un problema práctico mediante estándares de ingeniería de software.
Social o de contexto
Se abordará la problemática del manejo ineficiente de los recursos financieros cotidianos en los usuarios, proporcionando una herramienta móvil accesible y de uso inmediato que facilite el registro continuo de gastos, minimice errores humanos y optimice la toma de decisiones económicas personales o presupuestarias. De este modo, la aplicación aportará una solución práctica al alcance de la mano para responder a necesidades reales del entorno
